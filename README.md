# Statistiques bayésiennes — bureau d’études

Dépôt de travaux académiques de statistiques bayésiennes dans le cadre de la formation ISAE-SUPAERO.

## Contenu et navigation

- [2025-2026_bayes_BE_enonce.ipynb](2025-2026_bayes_BE_enonce.ipynb) : notebook principal.
- [data.csv](data.csv) : données présentes dans le dépôt.
- [DM_bayes.pdf](DM_bayes.pdf) : document associé au travail.
- `notes_de_cours.pdf` : support de cours.

## Consulter le travail

Commencer par le notebook et les documents associés. Pour une consultation locale, télécharger ou cloner le dépôt et ouvrir le notebook avec Jupyter dans un environnement adapté à son noyau.

Le notebook complet n’a pas pu être inspecté par l’outil de lecture lors de la préparation de ce README. La liste exacte des dépendances, les chemins attendus pour les données et la procédure d’exécution restent donc à vérifier avant d’annoncer une reproduction complète. Aucun résultat chiffré ou détail de méthode n’est extrapolé ici.

## Contexte

Ce dépôt rassemble du matériel académique et les travaux associés. La présence d’un support de cours ne vaut pas attribution de son contenu à l’auteur du dépôt.
